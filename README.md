
# KRX 종가매매 스캐너

코스피/코스닥 일봉 데이터를 바탕으로 종가매매 후보를 압축하는 Streamlit 앱입니다.

## 핵심 지표

- 20일 평균 거래대금
- 20일/60일 이동평균 추세
- 거래량 급증
- OBV
- CVD Proxy
- RSI(14)
- 20일 고점 접근/돌파
- MA20 이격률
- 당일 등락률

## 중요

`CVD Proxy`는 진짜 CVD가 아닙니다.  
일봉 OHLCV에는 개별 체결의 매수/매도 주도 여부가 없기 때문에,
캔들 내 종가 위치(Close Location Value) × 거래량의 누적값으로 대체합니다.

실제 CVD를 쓰려면 증권사 체결 API 또는 매수/매도 주도 체결량 데이터가 필요합니다.

## 실행 방법

### 1) Python 설치
Python 3.11~3.13 권장.

### 2) 폴더에서 설치
```bash
pip install -r requirements.txt
```

### 3) 실행
```bash
streamlit run app.py
```

브라우저가 열리면 `오늘 종가매매 후보 스캔`을 누릅니다.

## 기본 설정

- 스캔 종목 수: 시가총액 상위 300
- 20일 평균 거래대금: 30억원 이상
- 최소 주가: 2,000원
- 거래량: 20일 평균의 1.5배 이상
- RSI: 50~72
- MA20 이격: 12% 이하
- 당일 등락률: -2~+10%
- 20일 고점 5% 이내 접근
- 최소 점수: 75점

## 점수 구조

- 유동성 10
- 최소 주가 5
- 추세 20
- OBV 15
- CVD Proxy 15
- 거래량 15
- RSI 10
- MA20 과열 제한 5
- 당일 등락률 5
- 전고점 접근/돌파 최대 +10
- 최종 100점 상한

## 다음 업그레이드 후보

1. 미래에셋/키움 등 증권사 API 체결 데이터 연결 → 실제 CVD

3. 장 마감 10~20분 전 자동 실행
