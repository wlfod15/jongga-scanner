# KRX 종가매매 종목 스캐너 v5

Streamlit 기반 KRX 종가매매 후보 분석 도구입니다.

## v5 주요 기능

- 최종 매수후보 TOP5와 조건근접 TOP5 분리
- 하드필터 통과 종목이 없어도 조건근접 TOP5 표시
- 판정 및 구체적인 조건 탈락사유 표시
- 스캔 범위 밖 KRX 종목도 종목명·코드로 직접 검색 분석
- 반도체, 성장·기술, 에너지, 항공·운송, 일반 업종 필터
- Plotly OHLC 캔들·거래량·진입/손절/익절선
- VIX, 원/달러, 나스닥100 선물, 미국10년물, WTI, SOX, KOSPI, KOSDAQ 환경
- 외국인·기관 일별 및 5일 순매수/순매도, 공매도 거래·잔고 공개 통계
- OBV, CVD Proxy, 돌파형/눌림형/추세형, RSI, 종가위치, 윗꼬리, 거래량, 상대강도
- 과거 동일신호 백테스트와 진입·초기손절·1차/2차 익절·손익비
- 현재 특징과 가까운 과거 표본 기반 익일 확률·가격범위(ATR14 보정), 갭상승·+3%·손절 도달확률
- NXT 지연시세·USD/KRW·검증된 해외 24h 상품의 원화 환산가와 괴리율 원본 컬럼
- 모바일 1열 카드 화면과 유동 글꼴

## 해외 24h 상품 매핑

`overseas_products.csv`에서 KRX 코드별 해외 상품의 종류와 1:1 대응 검증 여부를 관리합니다.
`product_type=common_stock`, `verified_1to1=true`, `ratio=1`인 직접 대응 보통주만 환산합니다.
ADR·토큰화 주식·파생상품·미검증 상품은 가격을 임의 환산하지 않고 `비교 제외`로 표시합니다.
스캔 결과 CSV에는 원가격, 환율, 시각, 괴리율 원본 수치가 포함되어 추후 갭상승 백테스트에 사용할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

최종순위점수 가중치는 검증 전 설계값이며 투자 성과를 보장하지 않습니다. 공매도 수치는 KRX 공개 거래·잔고 통계로, 특정 투자자의 개별 포지션이 아닙니다.
